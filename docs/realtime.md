# 实时选股观察模块

`dragon_agent.realtime.recommend_realtime(frame, config=None, now=None)` 根据竞价、成交量、换手率和昨日涨停特征，返回可解释的排序观察名单。模块是固定规则研究程序，不能输出券商订单、目标仓位或交易许可，也不承诺稳定盈利。规则没有被证明能复刻任何特定交易者。

## 输出如何使用

每只股票的 `action` 有三种：

| 标记 | 含义 |
| --- | --- |
| 重点观察 | 规则得分达到默认 65 分、因子覆盖至少 60%，且日期、时段、数据可用时间、逐股行情时效及股票范围门禁通过；仍然只是研究观察 |
| 等待确认 | 数据缺失、陈旧、尚不可用、非交易时段，或得分不足；保留排序和原因，不能据此直接交易 |
| 回避 | 已知 ST、未开板新股、停牌、超出主板范围，或昨日连板计数不在研究范围 |

所有候选固定 `eligible=false`、`execution_ready=false`、`target_weight=0`；`recommendation_eligible=true` 只表示可标记“重点观察”。全局 `regime.allow_entries=false`。这种接口约定阻止其他模块把实时研究报告当作模拟或实盘下单计划。

`confidence` 是因子权重覆盖率，**不是胜率或价格预测置信度**。每个因子返回 `value`、`available`、`score`、`max_score`、`reason` 和 `provenance`。缺失值保持 null、贡献零分，不把剩余因子权重放大；已知为零与缺失严格区分。原始输入中的 NaN / Infinity 在输出中转为 null。

## 输入约定

适配器 `RealtimeCollector` 提供今日价格及竞价，缓存上一交易日涨停 / 炸板上下文，并按限定标的数查询昨日不复权日 K。上一交易日由交易日历确定，不直接用自然日前一天。

```text
frame:
  schema_version: 1
  source: demo | hithink | imported
  trading_date, previous_trading_date
  asof, available_at: 本次采集及首次可用的含时区 ISO 时间
  market_asof: 当前报价批次最新上游时间，可为 null
  previous_available_at: 本次获知昨日上下文的时间，可为今日
  is_trading_day: true | false | null
  session_status: preopen | auction | continuous | lunch | closed
  coverage: {complete, issues}
  stocks: [...]

stock:
  symbol, name, is_st, is_new, price, prev_close
  current_volume, current_turnover, current_turnover_pct
  quote_asof: 逐股行情时戳，可为 null
  batch_quote_asof: 不作为逐股行情时戳的替代
  auction:
    auction_pct, auction_amount, auction_volume, auction_turnover_pct
    auction_volume_ratio, auction_yesterday_ratio_pct, auction_unmatched
    data_status, auction_phase, asof
  previous:
    date, board_count, open_times, limit_up_time, final_seal_time
    volume, turnover
```

金额单位为元，成交量单位为股，百分数用百分点，例如 `auction_pct=2.5` 表示 2.5%。`open_times` 必须是已知的非负整数，不能从“未出现在炸板池”推断为 0。`is_new` 只是未开板新股标记，不能替代上市日期和所有特殊交易状态核验。

数据源的 `limit_up_time` 文档只称“涨停时间”，不保证是首次涨停时间，更不保证是最终封板时间。本模块将其标为“昨日涨停时间（非最终封板）”；`final_seal_time` 缺失时始终保持 null。两项评分独立，不互相填充。

## 已实现的评分

下表权重合计 100 分，均为可检验的启发式假设，没有胜率或收益保证。`clip(x)` 表示将值限制在 0 到 1。

| 因子 | 权重 | 规则 |
| --- | --- | --- |
| 竞价涨幅 | 15 | 0% 至 5% 为满分；-3% 至 0% 线性升分，5% 至 9% 线性降分，区间之外为 0 分 |
| 竞价成交额 | 15 | `clip(竞价额 / 3000万元)` |
| 竞价换手 | 10 | `clip(竞价换手百分点 / 0.5)`；只代表竞价阶段 |
| 来源竞价量比 | 10 | `clip(服务商量比 / 2)`；保留服务商口径，基准细节未独立验证 |
| 量参与度 / 时间折算量速 | 15 | 竞价阶段按竞价量占昨日日量 1% 封顶；连续时段按下文量速启发值 1.5 封顶 |
| 当前累计换手 | 10 | `clip(盘中累计换手百分点 / 5)`；缺失不能用竞价换手补齐 |
| 昨日开板次数 | 15 | `1/(1+开板次数)`；只对明确记录计分 |
| 昨日涨停池时间 | 5 | `clip((900-时刻分钟数)/300)`；不冒充首次或最终封板时间 |
| 昨日最终封板时间 | 5 | 同上；必须有独立的真实字段，不能从涨停池时间复制 |

换手分值和成交额分值采用封顶规则，并不意味着这些参数越大越值得买入；它们只是参与度和流动性代理。当前版本尚未验证最佳阈值、相互相关性或不同市值股票的可比性。

默认昨天连板计数范围为 1 至 6；上限使用普通配置 `max_board_count`。默认“重点观察”阈值使用普通配置 `min_score`。规则得分不因某项缺失而重新归一化，否则信息越少反而可能得到越高的虚假分数。

## 成交量口径

始终分别展示：

```text
当前量占昨日全日量（%） = current_volume / previous.volume × 100

连续时段量速启发值
  = (current_volume / previous.volume) / (已过连续交易分钟 / 240)
```

第一项只有一个昨日全日分母，所以不称为量比。第二项是假设成交量均匀分布的线性折算，不是历史同一时点的真实量比；开盘、尾盘成交量分布及竞价量会使它产生偏差。只有已过连续交易至少 15 分钟时才计算，避免刚开盘分母过小。

已过交易分钟分别计算 09:30—11:30 和 13:00—15:00，剔除午休。例如 10:30 为 60 分钟，13:30 为 150 分钟。集合竞价期间只用竞价量 / 昨日全日量，不按“距离 9:15 的分钟数”外推全天，也不把 `auction_yesterday_ratio_pct` 或来源量比偷偷换成上述新口径。

当前累计换手率必须有有效行情时间才能使用。真实联调发现股票池 timestamp 会随响应组装更新，历史查询也返回当前时间；不能据此证明盘中换手新鲜度。原值保留为 `raw_current_turnover_pct`，可评分字段 `current_turnover_pct` 保持 null，直到有可靠的行情时间证据。

竞价 `raw_auction_volume` 保留服务商原值；只有竞价价格乘数量与成交额一致（容许 0.01% 舍入差）才将 `auction_volume` 作为股数使用。真实样本出现过 100 倍差异，本程序不会未经确认直接乘 100。缺少量价额证据时相应量能因子缺失。

V2.0 双阶段模型在独立表中展示，详见 [model-v2.md](model-v2.md)。09:25–09:30 的开盘前空档允许采集终态竞价作为 V2 研究记录；原有连续交易推荐门禁仍保持关闭。

## 时间门禁

- 当日必须在交易日历中被明确标记为交易日，且与上海时区当前日期一致。周末、休市、盘前、午休及收盘后阻止“重点观察”。
- 观察时段为 09:15—09:25 集合竞价，以及 09:30—11:30、13:00—15:00 日内时段。09:25 后至 09:30 的非成交空档会等待确认；日内标签不声称可以在收盘集合竞价直接执行。
- 实时采集和行情最大年龄为 `min(max_data_age_seconds, 180)` 秒；延迟刷新后不会用新的采集时间包装旧行情。
- `available_at`、逐股报价、批次行情和竞价组装时间不能来自决策之后。昨日数据今天采集是合法的当前研究证据；它不能因此被回填为昨日已经获得的历史证据。
- 竞价 `data_status` 必须为 `ready`。9:25 前不能使用 `final`；`live` 阶段不能在开盘后冒充终态。当天可信的竞价终态可作为下午研究的历史上下文，不要求它每 180 秒重新发生一次。
- 竞价接口的 `asof` 是响应组装时间，不证明逐笔行情时效；报价批次时间也只是这一批中最新数据的时间，不证明每只股票都更新。

当前公开快照没有逐股时间戳，因此实时适配器保留 `quote_asof=null`。即使批次看起来很新、得分较高，默认也只显示“等待确认”的研究排序，不捏造强时效推荐。未来取得有明确逐股时戳的许可行情后，才能进一步验证该门禁。

`now` 参数用于确定性测试和合成演示。真实 CLI 采集应使用实际当前时间，不应人为设置过去时钟让历史数据冒充实时。演示报告必须显示 `source=demo` 与演示日期。

## 返回约定与验证

报告返回 `blocked`、`blockers`、`warnings`、`candidates`、时段及来源信息；`summary.actions` 汇总三类观察标签。分数降序、覆盖率降序、股票代码升序形成稳定排序。输入不会被修改；评分不调用网络、LLM 或券商。

测试覆盖真实零与缺失、未就绪竞价、提前读取终态、午休分钟剔除、每日量分母、竞价换手与盘中换手隔离、逐股与批次时间差异、未来时间、异常数值、非交易日、范围排除以及永不产生交易许可。离线测试证明规则和门禁按定义工作，不证明线上数据授权、交易者风格复刻或盈利能力。

交易时间与整手等规则依据 [深交所《交易规则（2026 年修订）》](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf) 的交易时段条款。该规则于 2026-07-06 起施行；本模块只提供研究观察，未来券商执行仍需独立核验行情、权限、程序化报告和实际撮合规则。
