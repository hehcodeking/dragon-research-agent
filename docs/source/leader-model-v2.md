# A股龙头股量化打分模型 V2.0
## —— 9:25 竞价版 + 10:00 盘中版（100分制）

> 适用风格：A股短线连板、主线题材、龙头股、换手龙、情绪周期交易  
> 核心思想：**先判断市场能不能做，再判断题材值不值得做，最后判断个股是不是核心。**  
> 本模型用于复盘、观察和交易纪律建立，不构成任何投资建议。

---

# 一、模型总览

这套模型拆成两个独立的 100 分评分体系：

- **9:25 竞价版**：解决“今天开盘前后，哪几只最值得盯？”
- **10:00 盘中版**：解决“开盘半小时后，谁真正走出了主动性、承接和龙头气质？”

二者不是简单重复，而是前后递进。

## 1. 9:25 竞价版的核心

9:25 时你还不知道：

- 个股开盘后的承接；
- 是否炸板；
- 是否回封；
- 板块是否真正联动；
- 龙头是否会带动跟风。

所以 9:25 版更重视：

**市场情绪 + 题材地位 + 个股辨识度 + 集合竞价超预期。**

---

## 2. 10:00 盘中版的核心

到 10:00，市场已经给出了大量真实信息：

- 谁高开低走；
- 谁低开高走；
- 谁分歧转一致；
- 谁主动带队；
- 谁只是跟风；
- 谁炸板后有人接；
- 谁冲高后无人承接。

所以 10:00 版把权重转向：

**主动性 + 分时承接 + 板块联动 + 换手质量 + 涨停质量。**

# 六、集合竞价：25分

这是 9:25 版最关键的“当日变量”。

核心公式：

**竞价强度 = 实际表现 - 市场原本预期**

不是简单看高开多少。

---

## 1）竞价价格超预期：10分

| 今日竞价 | 得分 |
|---|---:|

| +4% ~ +6% | 8 |
| +2% ~ +4% | 6 |
| 0 ~ +2% | 3 |
| 水下 | 0 |

### 情况B：昨日爆量烂板/大分歧

| 今日竞价 | 得分 |
|---|---:|
| > +5% | 10 |
| +3% ~ +5% | 8 |
| +1% ~ +3% | 6 |
| -1% ~ +1% | 3 |
| 明显低开 | 0 |

## 2）竞价成交额：6分

定义：

**R = 竞价成交额 / 昨日成交额**

| R值 | 得分 |
|---|---:|

| 2% ~ 3% | 5 |
| 1% ~ 2% | 3 |
| 0.5% ~ 1% | 1 |
| 过低/极端异常 | 0~2 |

注意：

**不是越大越好。**

竞价极端爆量但价格压不住，反而可能是兑现。

# 八、风险修正：5分

建议以“加分/扣分”形式处理。

初始给 5 分。

出现以下风险，每项扣 1~5 分：

- 高位严重异动风险；
- 监管风险；
- 重大减持；
- 板块核心出现连续核按钮；
- 昨日历史天量且无法修复；
- 同题材多个高位股同时爆量兑现；
- 竞价异常放量下压。

最低为 0 分。

**评分的意义不是“买入”，而是决定你开盘后盯谁。**

9:25 只做一件事：

> 从几十只涨停股里，筛到 3~5 只真正值得盯的核心。

## 2）回撤修复率：6分

定义：

**回撤修复率 = 反弹幅度 / 最大回撤**

例：

- 涨停价附近回落至 +6%；
- 最大回撤为 4%；
- 随后反弹至 +9%；
- 修复 3%。

则：

**修复率 = 3 / 4 = 75%**

参考：

| 修复率 | 得分 |
|---|---:|
| ≥80% | 6 |
| 60%~80% | 5 |
| 40%~60% | 3 |
| 20%~40% | 1 |
| <20% | 0 |

# 二十一、危险案例：竞价龙，开盘虫

### 9:25

某股票：

**92分**

看起来非常强。

但开盘以后：

- 高开8%；
- 30秒内迅速下杀；
- 巨量成交；
- 跌破均价线；
- 板块跟风不涨；
- 中军跳水；
- 竞争对手反而率先涨停。

### 10:00评分

可能变成：

**68分**

这就是典型：

> 竞价超预期 → 开盘兑现。

所以：

**9:25评分永远不能代替10:00确认。**

# 二十二、最值得关注的评分变化

## A类：85 → 90+

**强者恒强**

## B类：75 → 88

**低预期 → 超预期**

这类往往比：

# 二十六、一票否决机制

无论评分多高，以下情况需要直接降级甚至剔除：

1. 市场进入明显极端退潮；
2. 板块核心批量跌停；
3. 个股重大利空；
4. 重大监管风险；
5. 巨量高开后无承接；
6. 历史天量后持续走弱；
7. 龙头炸板后板块毫无回流；
8. 高标连续出现天地板；
9. 同身位竞争已经明确失败；
10. 评分很高，但所有优势都来源于“昨日数据”，今日并未确认。

---

# 二十七、最终核心公式

## 9:25

**龙头候选强度 = 市场环境 × 题材强度 × 龙头地位 × 竞价超预期 × 筹码结构**

重点解决：

> “今天应该盯谁？”

---

## 10:00

**龙头确认强度 = 主动性 × 承接 × 量价 × 板块联动 × 地位确认**

重点解决：

> “谁真正从候选龙头走成了今天的核心？”

---

# 二十八、最重要的一句话

真正的龙头交易不是：

> 找一只100分股票，然后无脑买入。

而是：

> **先用9:25评分找到最可能成为龙头的股票，再用9:30~10:00的真实资金行为确认市场是否认可你的判断。**

所以这套模型真正有价值的变量不是“今天多少分”，而是：

# **9:25分数 → 10:00分数的变化方向。**

例如：

- **82 → 93：强烈超预期**
- **90 → 94：强者恒强**
- **93 → 78：高开兑现**
- **72 → 88：弱转强/卡位成功**
- **85 → 65：伪龙头**

这才是模型真正用于短线交易的地方。

---

## 风险提示

本模型是用于短线交易研究、复盘和纪律建设的量化框架，不保证任何收益，也不能替代真实市场判断。A股短线连板交易波动和回撤风险很高，尤其在情绪退潮、高位股集中补跌、监管变化或突发利空时，历史模式可能快速失效。实际使用时应结合仓位管理、止损规则和个人风险承受能力。
