# 龙头股量化打分模型 V2.0：实现口径

本规则目录依据用户提供的《龙头股量化打分模型_V2.0_竞价版_盘中版.md》，用于研究、观察与复盘。源文件中的操作建议是模型内容，不是实盘下单授权，也不是收益承诺。两个阶段分别评分，不把9:25分数代替10:00确认。

## 接口与缺失处理

`dragon_agent.v2_rules.STAGES` 为 `("auction_0925", "intraday_1000")`。

`FACTORS[stage]` 列出因子的 `key`、`label`、`category`、`max_score`、`kind`；枚举因子的 `options` 是“中文选项→得分”字典。`score_factor(stage, key, value)` 返回 `float` 或 `None`。未知阶段、未知因子、缺失值、非法枚举、越界数值、布尔数值、数字字符串、非有限数均返回 `None`。字段不能跨阶段自动复用。

`None` 表示没有可用评分证据；观察明确为0分与缺失有区别。总分只累加已有证据，不对已覆盖权重重新归一化。覆盖率、来源、观测时间、阶段截止时间、数据新鲜度与一票否决由外层报告负责校验；纯计分函数不能证明证据真实或时点有效。接口没有的主观判断需要明确人工复核，不从缺失数据猜出满分。

百分数点与比例严格分开：`previous_premium_pct=3`、`auction_price.gap=3` 均表示3%；`advancement_rate=0.5` 表示50%；`auction_amount_ratio=0.03` 表示3%；`recovery_rate=0.8` 表示80%。计数使用非负整数。

## 原文未唯一确定处的约定

1. 区间重叠点取较低分；明确的不等式优先。比如昨日溢价1%/2%/3%依次为1/3/4分，晋级率30%/40%/50%依次为1/3/4分，竞价昨额比1%/2%/3%依次为1/3/5分。修复率80%按原文明确的“≥80%”计6分；40%/60%分别取1/3分。
2. 原文得分为范围时取下端：非身位核心0~1→0；过低/极端异常竞价昨额比0~2→0；回撤承接强7~8→7、较强5~6→5、一般3~4→3、弱0~2→0；9:50以后首次封板0~1→0；一般带动跟风1~2→1。
3. 因回撤承接“强”默认取7分，该保守实现盘中最高可得到99分；标称总权重仍为100，保留的1分不转移给其他因子、不人为补齐。
4. 题材扩散性原文未定义量化阈值。提供“人工评为强/中/弱”三个等级，分别2/1/0分；这是显式人工分级，不是根据涨幅、20cm数量或产业链覆盖自动计算的实盘判据。
5. 开盘成交额占比、炸板率、题材地位等没有数值阈值的项目保留原文定性枚举，不另造阈值。相关证据需要人工复核或未来有明确定义的专用数据源。
6. 涨停质量适用于10:00前已实际涨停的股票，外层应验证当天封板事实。未涨停、没有首次封板时间或只有无法区分首次/末次的池时间，不能填成“09:25”或0次炸板。`first_seal_time`只接受09:25~10:00的`HH:MM`；09:35按1分，09:50按0分。09:25允许实际竞价封板事件；10:00后事件不进入本阶段。
7. 原文要求“不炸或一次良性换手”才2分。`break_count=0`为2分，`2`为1分，`3`及以上为0分。单独输入`1`无法证实良性，返回缺失；输入`{"count":1,"benign":true}`才2分。非良性的1次炸板原文没有唯一得分，保留缺失而不自造档位。

### 竞价价格对象

```json
{"gap":7,"prior_pattern":"昨日强势缩量板","healthy_volume":true}
```

`prior_pattern` 只接受“昨日强势缩量板”或“昨日爆量烂板/大分歧”。健康量能字段是显式复核结论，不能由竞价额单点自动推断。

| 昨日形态 | 今日竞价gap，百分点 | 分数 |
|---|---|---:|
| 强势缩量板 | <0 | 0 |
| 强势缩量板 | [0,2] | 3 |
| 强势缩量板 | (2,4] | 6 |
| 强势缩量板 | (4,6] | 8 |
| 强势缩量板 | (6,9]且healthy_volume严格为true | 10 |
| 强势缩量板 | >9，或(6,9]但健康量能未确认 | 缺失 |
| 爆量烂板/大分歧 | <-1 | 0 |
| 爆量烂板/大分歧 | [-1,1] | 3 |
| 爆量烂板/大分歧 | (1,3] | 6 |
| 爆量烂板/大分歧 | (3,5] | 8 |
| 爆量烂板/大分歧 | >5 | 10 |

gap只接受[-100,100]内有限数值。原文未定义的强势缩量板>9%或高开量能不健康情形保留缺失；没有昨日形态时不可仅因高开就判10分。

### 风险对象

```json
{"reviewed":true,"deductions":[{"reason":"竞价异常放量下压","points":2}]}
```

只有`reviewed`严格为`true`且`deductions`是有效列表才可用。每项需非空`reason`和有限数值`points`，竞价每项0~5、盘中每项0~2；保留0允许明确记录已复核但未扣分的情况。总分分别为`max(0,5-扣分之和)`和`max(0,2-扣分之和)`。明确复核且空扣分列表可得满分；缺少复核、缺列表或任何无效扣分项都返回缺失。外层记录谁在何时根据什么来源复核。

竞价风险参考项：高位严重异动、监管、重大减持、板块核心连续核按钮、昨日历史天量无法修复、同题材高位股集中兑现、竞价异常放量下压。盘中风险参考项：持续放量回落、高位天地板、中军快速跳水、竞价强开盘兑现、异常爆量无法修复。这些是需查证的分类，不能因为数据源没返回风险就认定没有风险。

## 一票否决（独立于分数）

以下任意被明确证实时，应由报告直接降级或剔除；不能依靠其他高分抵消。没有观察证据时记为“未复核”，不能自动宣称已排除：

1. 市场进入明显极端退潮。
2. 板块核心批量跌停。
3. 个股重大利空。
4. 重大监管风险。
5. 巨量高开后无承接。
6. 历史天量后持续走弱。
7. 龙头炸板后板块毫无回流。
8. 高标连续出现天地板。
9. 同身位竞争已经明确失败。
10. 高评分只来自昨日数据，今日并未确认。

## 分数解释与动态比较

| 分数 | 9:25定义 | 10:00定义 |
|---:|---|---|
| ≥90 | 极强龙头候选 | 市场绝对核心 |
| [85,90) | 龙头级候选 | 强龙头 |
| [80,85) | 强核心 | 核心前排 |
| [75,80) | 有辨识度但有缺陷 | 次核心 |
| [70,75) | 普通强势股 | 强跟风 |
| <70 | 跟风或风险较高 | 跟风/弱势 |

这些是原文的研究标签，不代表概率、收益或自动交易指令。有缺失数据时必须同步展示覆盖率和缺失清单，不能把低覆盖分数包装成完整模型结论。9:25→10:00分差应同时展示两个阶段覆盖率、时点与否决状态；权重不同，分差也不等于投资收益或“资金净流入”。
